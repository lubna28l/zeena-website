About Zeena

Zeena is a smart beauty and salon booking mobile application developed using Flutter and Dart. The application helps users discover salons, search for beauty services, book appointments, manage favorites, and interact with a beauty community through a modern and elegant user interface.

The project focuses on usability, luxury UI/UX design, secure validation concepts, and future scalability. Zeena aims to provide an organized and reliable beauty service platform for customers and salons.

Conclusion & Future Work

The Zeena application successfully demonstrates a modern salon booking solution with elegant UI/UX and secure validation concepts. Future work includes full Firebase Authentication, online payment integration, real-time notifications, AI-powered recommendations, and dedicated dashboards for salon owners.

  • Project Objectives

    • Simplify salon booking
    • Improve service accessibility
    • Provide a luxury user experience
    • Support secure validation concepts
    • Build a scalable beauty platform

  • Technologies Used

    Flutter, Dart, Android Studio, Visual Studio Code, GitHub, Firebase concepts, Agile methodology, and UI/UX design principles.

  • Security Concepts

    The application includes input validation, password validation, secure login behavior, logout/session management, and verified review concepts to reduce fake feedback.
